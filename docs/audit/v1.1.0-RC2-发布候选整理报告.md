### 5.1 已实现（代码已落地）
- **P1 修复**：`DISABLE_RECEIVE_TOKEN` 纳入 33 项 `ENV_KEYS` 白名单，六个移植入口 `buildEnv()` 均透传——停用 `RECEIVE_TOKEN` 兜底在全部六平台生效（不再仅 Cloudflare）。

### 5.2 本地验证（隔离 / 本地可执行证据）
- `tests/run.mjs` **850/0**、`tests/p1-auth.mjs` **23/0**（含 `ENV_KEYS=33` 与 `verifyInboundToken` 行为矩阵）。
- 性能基准：隔离 `:memory:` SQLite 数据集（10k/100k），全场景 <2ms（统计面板 <6ms），大 offset 1.015ms vs 旧 66.78ms。
