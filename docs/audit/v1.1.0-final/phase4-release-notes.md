## 4.3 性能数据引用与边界（§8.2 关键约束）

引用来源：`docs/audit/02-性能基线报告.md`（真实历史报告，非编造）。发布说明 §4 完整写明：

- 环境 **Windows / Node v24.19.0 / 本地 SQLite (`node:sqlite`) / 单进程**；
- 数据集 **49,002 条活跃消息 / 10 台设备**，`runtime/bench/bench-50000.db`；
- 测量方式：完整 `fetchApp` 路径、每接口 20–60 次采样、报告 p50/p95，**接口 p50 而非纯 SQL 微基准**；
- 原始结果路径 `runtime/bench/result-*.json`，并注明**本地实验目录、未纳入版本控制、已被 `.gitignore` 排除**；
- 该报告头部**自带 2026-11-09 时效性勘误**，声明"不得作为当前发布依据"——发布说明原样转述，未把历史数字包装成 v1.1.0 当前性能承诺；
- 明确"与线上 D1/Turso 绝对延迟不可直接等同"；
- 四层证据边界：内存 SQLite / 本地 SQLite 有本地基准；**Turso 真实远端与真实部署均 NOT TESTED**；
- 本轮阶段2 的本地 Node HTTP 采样标注为 **n=5、空数据集、不构成性能结论**；
- EdgeOne `ensureSchema` 串行往返历史问题：明确**无实测、不采信历史估算、不作改善结论**。

✅ 未把本地 SQLite 数据写成 Turso / D1 / 生产性能数据。
