# 设置中心说明

入口：管理页右上角「⚙ 设置」直接打开设置中心；原设置下拉菜单已移除，统计入口在右侧栏「查看统计」，接入令牌在「安全」分组内。

设置中心按**用户理解**分组，而不是按源码顺序；每组独立保存，作用域在标题旁以徽章标注
（`全局` = 服务端 settings 表，影响所有浏览器；`本浏览器` = 当前浏览器 localStorage）。

## 1. 分组与设置项

### 登录与会话

| 设置 | 键 | 类型/范围 | 默认 | 作用域 | 保存位置 | 修改影响 |
|---|---|---|---|---|---|---|
| 界面语言 | `sms_lang` | 九语种 | 浏览器语言 | 本浏览器 | 浏览器 localStorage | 保存后整页重新加载并应用；不影响其他浏览器 |
| 分页设置 | `sms_perpage` | 10/20/50/100 | 10 | 本浏览器 | 浏览器 localStorage | 保存后立即生效（列表每页条数） |
| 登录有效期（本浏览器） | `sms_ttl_min` | int 5–43200 | 未设置=跟随全局 | 本浏览器 | 浏览器 localStorage | 仅本浏览器**之后的新登录**；不影响其他浏览器；不延长已签发会话 |
| 登录有效期（全局默认） | `session_ttl_minutes` | int 5–43200 | 30 | 全局 | D1 `settings` 表 | 未单独设置时按此签发；旧客户端（不声明）的兼容回退；仅影响之后的新登录 |

有效期优先级：**登录请求声明（本浏览器）> 全局默认 > 内置 30**。服务端强制校验整数 5–43200，非法返回
`400 INVALID_TTL` 且不签发会话；Cookie `Max-Age` 与 Token `exp` 同源。

### 通知

| 设置 | 键 | 类型 | 默认 | 作用域 |
|---|---|---|---|---|
| 自动复制验证码 | `sms_autocopy` | bool | 开启 | 本浏览器 |
| 后台通知 | `sms_notify` | bool | 开启 | 本浏览器 |
| 提示音 | `sms_sound` | bool | 关闭 | 本浏览器 |
| 免打扰 / 时段 | `sms_dnd` | `{on,start,end}` | 关闭 / 22–8 | 本浏览器 |
| 通知总开关 | `notify.enabled` | bool | 开启 | 全局 |
| 转发类型 | `notify.types` | `verify`/`sms`/`notify` | 全选 | 全局 |
| 失败重试 | `notify.retry` | 0–3 | 0 | 全局 |
| 跳转链接 | `notify.link` | url / 空 | 空（回退 `NOTIFY_LINK`） | 全局 |
| 渠道启用 | `notify.<channel>.enabled` | bool | 开启 | 全局 |
| 渠道凭据/参数 | `notify.<channel>.<field>` | 见 `NOTIFY_CHANNELS` | 环境变量或空 | 全局（**敏感**） |
| 多目标 | `notify.targets` | JSON 数组，≤50 项 | `[]`（回退单目标） | 全局 |

敏感字段只在服务端保存，界面只显示「已配置 + 掩码末位」；**留空 = 不修改**，勾选「清除」才删除已存值。
测试通知使用**已保存**的配置；多目标支持逐目标测试（`target_id`）。
`notify.targets` 非空时按目标逐个独立发送，单目标 `notify.<channel>.<field>` 仅作兼容回退；目标内敏感字段留空会沿用该 id 的旧密文。

### 数据与业务

| 设置 | 键 | 类型/范围 | 默认 | 作用域 |
|---|---|---|---|---|
| 消息保留天数 | `retention_days` | int 1–3650 | `RETENTION_DAYS` 或 30 | 全局 |
| 号码归属地查询 | `phone_area_enabled` | bool | true | 全局 |
| 归属地接口地址 | `phone_area_api` | url ≤500 / 空 | 空=内置免费接口 | 全局 |

### 安全

| 项 | 说明 |
|---|---|
| 接入令牌 | 打开令牌管理面板：创建 / 重命名 / 轮换 / 吊销；明文仅创建或轮换时显示一次 |
| 登录防护 | 5 次密码错误锁定 10 分钟；无状态签名 Token（只读展示，不在界面改动） |

> 本项目**不存在平台级（按部署平台区分）的设置项**，因此不设「当前平台」分组，也不虚构该类配置。

## 2. 保存 / 取消 / 重置

- **保存**：按分组局部 `PUT /api/settings`（`revision` 乐观锁）；仅修改浏览器偏好（语言/分页/消息开关/免打扰/浏览器时长）时不发请求，直接写 `localStorage`。
  保存中按钮进入加载态，成功 `toast`，失败显示可读原因（如 `REVISION_CONFLICT`），**不把失败伪装成成功**。
  界面语言保存后会整页重新加载；分页设置保存后立即生效。
- **未保存状态**：任一输入变更即在标题显示「未保存」徽章并出现「取消」按钮；切换分组会提示将丢弃修改。
- **取消**：丢弃未保存修改，回填到最近一次已保存的值（不写服务端）。
- **恢复默认**：按分组填回默认值（需确认后点保存才写入）：
  - 登录与会话：清除本浏览器时长 + 全局默认 30 分钟（语言/分页保持当前浏览器值）
  - 通知：本浏览器开关与免打扰恢复默认；全局开关开启、类型全选、重试 0、链接清空（**渠道凭据与多目标不变**）
  - 数据与业务：30 天、归属地开启、接口地址清空

## 3. 兼容与边界

- 接口路径、字段名、响应结构、设置键名与默认值**均未变更**，旧客户端与旧数据库零操作兼容。
- 浏览器独立有效期功能（v1.0.4）未重新实现，仅在界面表达与分组上归位。
- 敏感凭据加密属后续安全专项，本轮不涉及。
