## 2. 本版本升级目标

1. **跨平台一致性**：修复 `DISABLE_RECEIVE_TOKEN` 在五个移植入口被 `ENV_KEYS` 白名单静默丢弃的问题，使六平台透传集合一致。
2. **通知可靠性边界**：后台通知任务登记与有界等待、失败隔离、超时真实终止；明确 best-effort 语义，不夸大送达保证。
3. **大规模消息下的响应性能**：列表/搜索/筛选/深翻页/设备列表在 5 万条量级的本地基线显著改善。
4. **Node 自托管停机安全**：80 秒应用整体宽限与优雅 drain，避免升级重启时丢失在途通知。
5. **可用性与国际化**：1180px 仪表盘、设置中心重构、消息列表摘要与游标分页、9 语言界面、PWA 多语言。
6. **发布可审查性**：源码、六平台产物、测试、文档、审计证据形成可精确提交的变更集。

### 4.2 必须随数据一起阅读的限定

1. 该报告**头部自带 2026-11-09 时效性勘误**，明确声明："本报告为历史时点的验收底稿，其中的数字与描述只代表当时状态，**不得作为当前发布依据**"。因此上表**不代表 v1.1.0 当前构建的性能承诺**。
2. 报告本身说明："与线上 D1/Turso 的绝对延迟**不可直接等同**；线上还叠加网络 RTT 与平台调度"。
3. **这些数据是本地 SQLite 的，不是 Turso、不是 Cloudflare D1、不是任何生产环境性能数据。**
4. 四层证据边界（RC1 建立）：**内存 SQLite / 本地 SQLite** 有本地基准；**Turso 真实远端** 与 **真实部署** 均 **NOT TESTED**。

6. **EdgeOne 历史性能问题**（`fetchApp()` 中 `ensureSchema()` 串行数据库往返）：本轮无 EdgeOne 实例与 Turso 凭据，**未取得任何实测延迟**；历史估算不作为当前实测结果，也不作任何性能改善结论。

## 5. 会话有效期相关变化

- 会话时长升级为**浏览器独立**：管理页「会话时长」读写浏览器本地配置（localStorage `sms_ttl_min`），登录时随请求声明，服务端校验 **5~43200** 分钟后按声明签发独立 exp。
- `settings` 表的 `session_ttl_minutes` 保留为**全局默认值/兼容回退**；未声明时行为与旧版一致。
- 已签发会话的过期时间在签发时确定，不会被延长或缩短；改一个浏览器不影响其他浏览器。
- 证据：**已实现 + 本地测试通过**；未在生产会话场景验证。

## 6. 通知多目标相关变化

- 通知渠道支持**每渠道多个独立目标**（`notify.targets`），旧单目标配置与旧环境变量在 `notify.targets` 为空时回退生效。
- 单个目标失败不阻断其余目标；超时经 `AbortSignal.timeout` 真实终止底层请求。
- ⚠️ **通知转发为 best-effort**：本项目**不承诺 exactly-once 送达**，**不提供跨实例/跨重启的持久化后台任务队列**；后台任务超时不取消、不补偿，消息已入库但通知可能遗漏。这是明确的架构边界，不是缺陷。
- 证据：**已实现 + 本地测试通过（失败隔离/超时行为）**；**所有 11 个渠道的真实投递均未验证（NOT TESTED）**，接口返回成功不等于真实送达。

## 7. 消息列表与分页优化

- 默认 **10 条/页**、两行摘要（≤120 码位，Unicode 安全）、「加载更多」游标分页，不拉取全量历史。
- 游标携带**星标 ID 集合的 SHA-256 指纹**；分页期间星标集合变化则服务端返回 `409 CURSOR_STALE`，前端回到首屏，避免跳过或重复。
- 新增单条详情接口、`slim=1` 摘要瘦身、`read=1` 筛选；未传 `slim`/`cursor` 时旧调用方仍按 `page` 分页返回完整正文。
- 证据：**已实现 + 本地测试通过 + Node 本地真实运行通过**（`/api/messages`、`/api/export?format=json` 响应结构正确）。

## 8. UI、设置页与国际化改进

- 管理页 1180px 仪表盘（左列表 + 右设备/设置概览/快捷统计）；验证码卡片顶部主色胶囊一键复制；右键/长按进入多选；5 秒删除撤销。
- 设置中心重构：分组、作用域徽章、未保存确认；新增界面语言、分页、本浏览器偏好（消息开关 + 免打扰）。
- 界面内置 **9 种语言**（zh-CN / zh-TW / en / ja / ko / es / fr / de / pt-BR），日期、相对时间、号码标签随之切换；`?lang=` 深链与浏览器本地记忆；PWA 多语言。
- **i18n 镜像维护方式调整**：不再在译文文件里写入同步提示/免责块，译文对应关系以 Git 历史为准；`ENV_KEYS = 33` 等当前事实已在正文中定点订正。9 语言镜像的滞后译文正文未整体重译，详见 §11。
- 证据：**已实现 + 本地测试通过 + 静态多视口渲染（历史 RC1）**；**真实后端驱动的动态 UI 端到端流程 NOT TESTED**。

## 9. 六个平台适配情况

**源码层面六个平台均由同一 `src/worker.js` 生成/同步，功能设计一致；但"源码适配"≠"真实运行通过"。**

| 平台 | 入口 | 源码/产物一致性 | 本轮真实运行证据 | 结论 |
|---|---|---|---|---|
| Cloudflare Workers + D1 | `platforms/cloudflare/worker.js` | ✅ 逐字节 ≡ `src/worker.js` | ❌ 无（无 wrangler、无 `.dev.vars`、无实例、无 D1 绑定验证） | **BLOCKED** |
| Vercel + Turso | `api/[[...route]].js` | ✅ `app.js` ≡ shared，ENV_KEYS 33 | ❌ 无（无 CLI、无实例、无 Turso 凭据） | **BLOCKED** |
| Deno Deploy + Turso | `main.js`（`Deno.serve`） | ✅ 同上 | ❌ 无（**Deno 运行时不可用**） | **BLOCKED** |
| Netlify Functions + Turso | `functions/api.mjs` | ✅ 同上 | ❌ 无（无 CLI、无实例、无凭据） | **BLOCKED** |
| EdgeOne Makers + Turso | `functions/index.js`（`onRequest`） | ✅ 同上 | ❌ 无（独立部署项目，无实例/凭据） | **BLOCKED** |
| Node.js + Docker + Turso/SQLite | `server.mjs` / `Dockerfile` | ✅ 同上；`node/db.js` 为有意差异的双适配器 | ⚠️ **本地 Node 裸进程 + 本地 SQLite 真实 HTTP 运行通过**；容器/Turso 模式未验证 | **CONDITIONAL PASS** |

> 版本一致性（`gen_app.py --check`、SHA256 比对）只证明**产物一致**，不证明任何平台能启动或能连上数据库。

## 10. 兼容性与升级注意事项

- **零操作升级**：绝大多数用户只需更新代码 + 重新部署；`ensureSchema` 在首次请求幂等建表/补列/建索引，**不需要手动执行 SQL**。
- **不新增表/列/索引**（相对 v1.0.4 之后的工作树）；`notify.targets` 与设置项仍存于既有 `settings` 键值表。
- **环境变量**：`RECEIVE_TOKEN` 保持兼容；`DISABLE_RECEIVE_TOKEN` 现已在六平台生效，默认（未设置）仍保留兜底启用，仅 `"true"`（大小写/空白不敏感）停用。库内命名令牌优先级高于该开关。
- **旧调用方**：不传 `slim`/`cursor` 时行为不变；默认每页由 20 改为 10 仅影响未显式传 `limit` 的调用。
- **Node 自托管停机**：应用整体宽限 **80s**，容器/服务停止宽限必须 **≥90s**；Docker 默认 10s 会先 SIGKILL，升级重启前务必配置，否则在途通知可能丢失。
- **回退**：保留 `RECEIVE_TOKEN` 环境变量即安全；回退前**不要**设置 `DISABLE_RECEIVE_TOKEN="true"`。
- 详细步骤与备份/恢复/失败排查见 [升级指南](../UPGRADE.md)。
