## 1. 本次变更

### 中文

- **设置中心交互与异常恢复优化**：保存后不再关闭弹层，自动回读最新配置并停留在当前分组；新增 revision 冲突的就地恢复入口（「重新加载最新配置」），冲突时保留用户未提交的输入；重复点击保存不再产生第二次写入；未保存修改在切换分组或关闭弹层时给出确认；「安全」分组不再显示无效的保存按钮。
- **通知目标管理体验**：新增/编辑推送时前置提示必填项，删除目标时确认框显示目标名称；测试发送成功与失败均如实提示，单个目标失败不影响其他目标。
- **消息列表异步请求竞态修复**：`loadSeq` 同时保护成功与失败分支——过期请求即便失败，也不会用「加载失败/重试」覆盖最新请求的结果；最新请求失败时重试入口照常可用。
- **统计图表显示修复**：统计弹层柱状图填充条改为块级元素，百分比宽度不再渲染为 0，比例与数值一致。
- **巴西葡萄牙语国际化修复**：`pt-BR` 语言代码此前被归一化为 `pt-br` 而无法命中，现已可正常切换；本轮新增文案同步补齐九种语言。
- **退出登录流程**：顶栏提供退出入口，先调用 `/api/logout` 再清理前端临时状态；接口异常时如实提示失败，不伪造退出成功。

### English

**v1.1.1 Test Release**

- Improved settings center save and recovery workflows: the dialog stays open after saving, the latest revision is re-read in place, and revision conflicts offer an inline "reload latest settings" action that keeps unsaved input.
- Fixed stale asynchronous message-list request handling: a superseded request can no longer replace the current result with a retry/error state, while the newest failure still surfaces a retry entry.
- Improved statistics chart rendering: bar fills are block-level, so percentage widths render at the correct size.
- Improved notification target management feedback: required fields are shown up front, delete confirmation names the target, and test sends report success and failure honestly.
- Fixed Brazilian Portuguese locale normalization (`pt-BR`).
- Preserved existing notification channel and multi-target semantics: 11 channels, multiple targets per channel, stable `target_id`, revision optimistic locking, and per-target failure isolation are unchanged.
