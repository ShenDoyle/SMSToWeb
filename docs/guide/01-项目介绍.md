# SMSToWeb 是什么

> 一句话：**把手机收到的短信和 App 通知，自动汇总到一个网页上，随时随地查看。**

## 它能帮你解决什么

| 你的麻烦 | SMSToWeb 怎么解决 |
|---|---|
| 手机不在手边，验证码收不到 | 短信实时同步到网页，在电脑上就能看到并一键复制验证码 |
| 多台手机 / 多个设备的通知分散 | 全部汇到同一个页面，按来源、关键词、时间筛选 |
| 想让重要消息自动提醒到群里 | 支持转发到飞书 / 企业微信 / 钉钉 / Telegram / Bark / 邮件等 11 种渠道 |
| 想留存、导出消息 | 支持按当前筛选导出 CSV / JSON |

工作方式很简单：

```
手机（安卓 SmsForwarder 或任意脚本）
   └─ 发送一条 HTTP 请求 ─→ 你部署的 SMSToWeb ─→ 存进数据库
                                    └─→ 网页自动刷新显示 / 可选转发到群
```

## 支持哪些平台

Cloudflare Workers（推荐）、Vercel、Netlify、Deno Deploy、腾讯 EdgeOne Makers、Node / Docker 自托管，共 6 种。**功能完全一样、数据格式一样，以后可以换平台。**

各平台「一键部署」到底能自动做什么，见 [部署能力矩阵](10-部署能力矩阵.md) —— 结论是**没有哪个平台能点一下就完全不用管**，请先看一下再选。

## 你需要准备什么

| 项目 | 是否必须 | 说明 |
|---|---|---|
| 一个平台账号 | ✅ | 推荐 Cloudflare，免费、不用服务器 |
| 一个 GitHub 账号 | ✅（用部署按钮时） | 按钮会把代码克隆到你自己的仓库 |
| 一个自己编的「推送密钥」 | ✅ | 叫 `RECEIVE_TOKEN`，32 位以上随机串 |
| Turso 数据库账号 | 仅非 Cloudflare 平台 | [turso.tech](https://turso.tech) 免费，需要建库并记下地址与令牌 |
| 服务器 | ❌ | 只有选 Node 自托管才需要 |
| 自己的域名 | ❌ | 平台会免费给一个地址；想用自有域名以后再绑 |
| 会写代码 | ❌ | 全程点按钮 + 填表；只有「发第一条测试消息」需要一条命令 |

## 要不要花钱

**可以完全零成本**：Cloudflare 免费额度对个人使用足够，不需要信用卡，也不需要域名。

可能产生费用的情况：

- 选 Vercel Hobby：官方明确限定**非商业、个人用途**；
- 选 Fly.io / Railway / VPS 自托管：服务器本身要钱；
- 绑自有域名、购买短信转发服务等额外需求。

各平台免费额度与限制见 [部署能力矩阵](10-部署能力矩阵.md) 第 3 节。

## 它不能做什么（明确说明，不模糊承诺）

- **不能替你注册平台账号、不能替你填密钥**——部署按钮只把代码变成运行中的应用。
- **当前版本网页里没有「给自己发一条测试消息」的按钮**：发测试消息要用手机转发端或一条命令（见 [快速开始](02-快速开始.md)）。这个缺口已记录在 [界面交互问题清单](08-界面交互问题清单.md)（B-6），需审批后才能改。
- **不能保证通知一定送达**：后台通知有 45 秒等待上限，超时会明确记录但不会补发；消息本身已入库不会丢。
- **不能代替备份**：请按 [更新与维护](09-更新与维护.md) 定期导出或备份数据库。
- **五个 Serverless 平台本轮没有做过真实部署验证**；文档里的平台能力来自官方文档，不是实测。
