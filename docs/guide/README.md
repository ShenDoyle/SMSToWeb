# SMSToWeb 用户文档（从这里开始）

> 这份文档是给**第一次使用 SMSToWeb 的普通用户**看的。你不需要懂源码、数据库、API 或服务器架构。
> 每一篇都先告诉你「点哪里、填什么」，再告诉你「怎么算成功」；看不懂的术语一律放在最后解释。

## 三、部署方式能力速览

| 平台 | 有没有官方部署按钮 | 点完还要做什么 | 详细指南 |
|---|---|---|---|
| **Cloudflare**（推荐新手） | ✅ 有 | 填 `RECEIVE_TOKEN` 等密钥；**建表由应用首次请求自动完成，不是按钮做的** | [指南](03-平台部署/01-Cloudflare.md) |
| Vercel | ✅ 有 | 先建 Turso 数据库、填 3 个环境变量、执行建表 | [指南](03-平台部署/02-Vercel.md) |
| Netlify | ✅ 有 | 先建 Turso、填 Base directory、填环境变量、执行建表 | [指南](03-平台部署/03-Netlify.md) |
| Deno Deploy | 平台有，本项目**未提供按钮** | 走 Git 导入 + 控制台补环境变量 | [指南](03-平台部署/04-DenoDeploy.md) |
| 腾讯 EdgeOne Makers | 平台有，本项目**未提供按钮** | Git 导入 + 手动配置；注意国内备案与预览链接有效期 | [指南](03-平台部署/05-EdgeOne.md) |
| Node / Docker 自托管 | ❌ **没有一键部署** | 全程手动，并且**必须配置 ≥90 秒停止宽限** | [指南](03-平台部署/06-Node自托管.md) |

> 按钮属于「模板部署」：能帮你把代码变成运行中的应用，密钥与外部数据库仍需自己填写。详见 [部署能力矩阵](10-部署能力矩阵.md)。

> **版本提示**：部署按钮拉取的是公开仓库 `main` 分支；以管理页页脚版本号为准。
