# 六平台部署能力矩阵（官方核实，2026-11-09）

> 目的：**不夸大「一键部署」**。逐个平台核实官方到底能自动做什么、哪些仍需你填写，并给出可核验的官方出处。
> 核实方式：访问平台官方文档页面（WebFetch 抓取正文 / WebSearch 命中官方 URL 摘要），核实日期 **2026-11-09**。
> 标注「抓取」= 打开该官方页读到正文；「检索」= 搜索命中该官方 URL 的摘要、未逐页抓取；「未核实」= 官方文档中没有找到明确说明。

---

## 一、归类定义（先统一口径）

| 类别 | 含义 |
|---|---|
| **A 真正一键部署** | 点一下就部署完成，**无需填写任何配置** |
| **B 模板部署** | 有官方按钮，点完**仍需填写少量配置**（密钥、数据库等） |
| **C GitHub 导入后手动配置** | 不用按钮，直接 Import 仓库，随后手工配置 |
| **D 完全手动部署** | 平台侧没有按钮、没有导入、没有自动资源创建 |

**结论：没有任何一个平台达到 A 类。** 五个 Serverless 平台都有真实的官方按钮，但按定义全部属于 **B**；C 是「不走按钮」时的退化路径；Node 自托管是 **D**。

## 二、六平台归类总表

| # | 平台 | 归类 | 官方按钮 | GitHub 导入 | 按钮自动建数据库 | 点完仍需你做的最少事项 |
|---|---|---|---|---|---|---|
| 1 | **Cloudflare Workers** | **B**（最接近一键） | ✅ Deploy to Cloudflare | ✅ 克隆到你的 GitHub/GitLab | ✅ **仅 D1/KV/R2 等平台原生资源** | 账户授权、设置页填 `RECEIVE_TOKEN`（开启登录再加 2 项）；**建表由应用首次请求 `ensureSchema` 完成，不是按钮** |
| 2 | **Vercel** | **B** | ✅ Deploy Button | ✅ | ❌ | 先建 Turso 库、填 3 个环境变量、执行建表 SQL |
| 3 | **Netlify** | **B** | ✅ Deploy to Netlify | ✅ | ❌ | 先建 Turso 库、填 `Base directory`、填环境变量、重新部署、执行建表 |
| 4 | **Deno Deploy** | **B**（按钮能力弱） | ✅ Deploy Button（官方存在） | ✅ | ❌ | 控制台手填环境变量（按钮无 env 参数）、外部建 Turso、执行建表 |
| 5 | **腾讯 EdgeOne Makers / Pages** | **B**（地区限制最重） | ✅ Deploy Button（官方存在） | ✅ GitHub / Gitee | ❌ | 填 `env`、建 Turso、手动开通/绑定 KV、处理备案与预览链接有效期 |
| 6 | **Node / Docker 自托管** | **D** | ❌ 无官方一键部署 | ❌ 平台侧不存在 | ❌ | **全部**：服务器、镜像、端口、卷、密钥、域名/TLS、备份、**≥90s 停止宽限** |

> **关键前提**：Turso 是第三方外部数据库，**不属于任何一家部署平台的托管资源**。六个平台的按钮/导入流程都没有官方文档说明会自动创建 Turso。唯一被官方文档明确「按钮自动创建并绑定数据库」的是 **Cloudflare D1**。

## 五、所有 Turso 系平台的共同「数据库段」（必须手动）

Vercel / Netlify / Deno Deploy / EdgeOne 的按钮只解决「代码 → 运行」，数据库这段一律手动：

1. 注册 [turso.tech](https://turso.tech) → 创建 group / database；
2. 生成 auth token（**只显示一次，立即保存**）→ 执行建表（把对应平台目录的 `schema.sql` 粘进 Console 执行，或靠应用首次请求自愈）；
3. 把 `TURSO_DATABASE_URL` / `TURSO_AUTH_TOKEN` 填进平台环境变量 → 必要时**重新部署**。

因此诚实的宣传语是 **「一键部署应用 + 三步配置数据库」**，不是「一键部署」。

## 六、若要真正接近 A 类的唯一现实路径

把某个平台的数据库换成**平台原生、且按钮能自动 provision** 的资源：

- ✅ **Cloudflare D1**：官方明确按钮自动创建并绑定 → 已可行，是六平台里唯一接近「点完就能用」的组合。
- ⚠️ Deno KV：内置免开通，但要改数据层，且按钮不建 Turso。
- ⚠️ Netlify Database / Blob：pricing 页称可自动 provision，但**未在 Deploy Button 流程中确认**。
- ❌ EdgeOne KV：官方文档明确要求手动开通/建命名空间/绑定。
- ❌ Turso：任何平台都不自动创建。
