# 腾讯 EdgeOne Makers 部署指南

> 国内访问体验好，但**地区与备案限制是六个平台里最重的**，请先读完「限制」一节再决定。
> 需要先准备 Turso 数据库（见 [平台部署总览](README.md)）。完整技术版：[platforms/edgeone/README.md](../../../platforms/edgeone/README.md)。

## 部署入口（点哪里）

**本项目目前没有提供 EdgeOne 的一键按钮。** 最短路径是控制台 Git 导入：

1. 打开 EdgeOne 控制台 → 进入 Pages / Makers。
2. 选 **导入 Git 仓库**（支持 GitHub、Gitee 等），授权后选你 Fork 的仓库。
3. 把部署根目录指到 `platforms/edgeone`。

> 平台官方**确实有** Deploy Button（`https://edgeone.ai/pages/new?repository-url=<encoded>`）与模板市场，但本项目**未提供、也未在真实平台验证**，不宣称可用。见 [部署能力矩阵](../10-部署能力矩阵.md)。

## 点击步骤

1. **先建好 Turso 库**并记下 URL / Token。
2. 控制台导入 Git 仓库 → 自动识别框架（本项目零构建，构建/安装命令可留空）。
3. 在 **项目设置 → 环境管理** 按「生产 / 预览」分别填下面几项。
4. （如用平台 KV）控制台「存储 - KV」→ 申请开通 → 建命名空间 → 绑定命名空间并定义变量名。这是**手动流程**，按钮不会代做。
5. 点 **创建 / 部署**，等待完成。
6. **执行建表**：把 `platforms/edgeone/schema.sql` 粘进 Turso Console 执行，或依赖应用首次请求自愈。
7. 用控制台「预览」生成链接访问，或绑定自定义域名。

## 需要填写的内容

| 字段 | 示例 | 说明 |
|---|---|---|
| 加速区域 | 「全球可用区（不含中国大陆）」 | 影响是否需要备案、中国大陆能否访问 |
| 构建/安装命令 | 留空 | 本项目零构建 |
| 根目录 | `platforms/edgeone` | 入口在 `functions/index.js` |
| `RECEIVE_TOKEN` | `tK8mQ2xV7pL...` | 自己生成 |
| `TURSO_DATABASE_URL` / `TURSO_AUTH_TOKEN` | Turso 的两项 | 只显示一次的令牌要立即保存 |
| `ENABLE_AUTH` / `ADMIN_PASSWORD` / `SESSION_SECRET` | 见 [快速开始](../02-快速开始.md) | 建议开启登录 |

> 变量名 ≤255 字节、值 ≤1000 字节；**环境变量更改只影响新部署**，改完要重新部署。

## 限制（务必先读）

| 限制 | 后果 |
|---|---|
| 中国大陆访问默认项目/部署域名 | 必须用控制台生成的**预览链接，有效期 3 小时**，超时返回 401，需要定期刷新 |
| 「全球可用区（不含中国大陆）」默认域名 | 中国大陆访问返回 401 |
| 含中国大陆的可用区绑自定义域名 | **必须完成工信部备案** |
| 自定义域名 DNS 生效 | 最长 48 小时，平台验证通过后自动配 SSL |
| 免费版具体配额数值 | 官方 FAQ 只说「每月定额，在控制台用量概览查看」，**未在文档给出具体数字**；KV 免费版 1GB |
| 账户 | 腾讯云通用文档说明中国站使用云服务须实名认证，Pages 专门页未明确 → 以控制台实际要求为准 |

## 成功标志

- 部署详情页状态成功；用预览链接或已绑定的自定义域名能打开管理页；
- 发一条测试消息后页面出现数据。

## 常见错误及解决办法

| 现象 | 先试这个 |
|---|---|
| 预览链接 401 | 预览链接 3 小时过期，回控制台点「预览」刷新；长期用请绑自定义域名 |
| 国内打不开 | 检查加速区域选择；想国内稳定访问需自定义域名 + 备案 |
| 页面无数据 | 检查环境变量填在「生产」还是「预览」；确认 Turso 已建表；变量改动后重新部署 |
| 找不到入口 | 确认根目录 `platforms/edgeone`，根路径 `/` 只认 `functions/index.js` |
| 直接用「上传」部署后想换 Git | 官方说明直接上传的项目无法再切换到 Git 集成，需重建项目 |
